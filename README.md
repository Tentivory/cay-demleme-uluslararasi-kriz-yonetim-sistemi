# ÇAY DEMLEME ULUSLARARASI KRİZ YÖNETİM SİSTEMİ

## Resmi Protokol Belgesi | Seviye: ULTRA CİDDİ

**Uyarı:** Bu repo şaka değildir. Çay demlemek ciddi bir iştir. Çay kaçarsa dünya durur. Biz de bu yüzden buradayız.

### Projenin Amacı

Çay demleme sırasında meydana gelebilecek her türlü felaketi (çayın kaçması, suyun soğuk olması, şekerin bitmesi, komşunun çay istemesi) önceden tespit edip dünyayı kurtarmak.

Bu sistem, Türkiye Cumhuriyeti'nin en stratejik gıda maddesi olan çayın korunması için geliştirilmiştir. Çay yoksa hayat yoktur. Hayat yoksa... işte o zaman sorun büyük.

### Nasıl Çalışır?

1. `python cay_kriz_yonetimi.py` komutunu çalıştırın
2. Sistem suyu ısıtır (sanal olarak)
3. Çay yapraklarını konumlandırır (yine sanal)
4. Kriz seviyesini hesaplar
5. Gerekirse dünyayı kurtarır

### Kriz Seviyeleri

| Seviye | Anlamı | Eylem |
|--------|--------|-------|
| YEŞİL | Her şey normal | Afiyet olsun |
| SARI | Su biraz soğuk | Dikkat |
| TURUNCU | Çay kaçmak üzere | Alarm |
| KIRMIZI | Çay kaçtı | Ulusal felaket |
| SİYAH | Çay yok | Medeniyet çöktü |

### Kurulum

```bash
git clone https://github.com/Tentivory/cay-demleme-uluslararasi-kriz-yonetim-sistemi.git
cd cay-demleme-uluslararasi-kriz-yonetim-sistemi
python cay_kriz_yonetimi.py
```

Python 3 yeter. Başka bir şeye ihtiyacınız yok. Çay hariç.
